# 01: Design — Google sign-in control + admin sign-in surface

**What to build:** The visual design, in the existing "The Route" design system
(DESIGN.md tokens), for (a) a "Continue with Google" sign-in button and (b) the
`/admin` anonymous sign-in surface a signed-out visitor sees. Design only — tokens,
states, layout — no application logic.

**Blocked by:** None (can start immediately).

**Frontier:** F1
**UI:** yes

- [ ] "Continue with Google" button designed in tokens: default, hover, focus-visible,
      disabled/loading states; placed beside the existing email-OTP control without
      crowding it.
- [ ] Admin anonymous sign-in surface designed: on-brand, minimal, reveals nothing about
      the admin area beyond the sign-in itself.
- [ ] Light and dark treatments both covered (role-swap per DESIGN.md).
- [ ] Accessible: visible focus, sufficient contrast, control labels.
- [ ] Owner sign-off on the running screen (design gate).
